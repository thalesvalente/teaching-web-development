1 · Antes de começar: quem controla o quê?

O projeto-base da disciplina continua em lessons/aula-02-vite-vue-componentizacao. Quando o sistema de missões estiver habilitado, a divisão será esta:

course/Missões e verificadores publicados pelo professor. Não edite sem orientação.
src/Seu código Vue. É aqui que você implementa e evolui a aplicação.
origin e upstreamDois endereços Git diferentes: um entrega; o outro recebe.
Seu trabalho não é descartável. A partir da Aula 3, você continua no mesmo projeto e registra cada incremento com commits.

4 · Por que não usar git pull upstream main?

❌ git pull upstream main

Busca e tenta integrar todo o repositório. Como você altera arquivos em src/, podem surgir conflitos desnecessários.

✅ runner update

Quando habilitado na disciplina, o atualizador é o caminho previsto para buscar as novas missões preservando o código do aluno.

Não use git pull upstream main salvo orientação explícita do professor.

8 · Problemas comuns

Abra somente o erro que apareceu no seu terminal.

fatal: not a git repository
Você está fora da pasta clonada. Entre novamente em teaching-web-development e rode git status.
remote upstream already exists
Não crie outro remote. Rode git remote -v. O upstream correto deve apontar para https://github.com/thalesvalente/teaching-web-development.git.
Meu origin aponta para o professor
Correção
git remote rename origin upstream
git remote add origin https://github.com/SEU_USUARIO/teaching-web-development.git
git push -u origin main
O atualizador informou alterações em course/
Confira primeiro com git status. Se você editou course/ sem querer e não precisa dessas mudanças, use git restore course e tente o update novamente. Se houver algo importante em course/, fale com o professor antes de restaurar.
node course/runner.mjs update não encontra course/
Você pode estar na pasta errada, ou o professor ainda não publicou o sistema de missões para essa versão. O terminal deve estar em teaching-web-development/lessons/aula-02-vite-vue-componentizacao.
Apareceram <<<<<<<, ======= e >>>>>>>
Isso indica conflito de merge. Não apague as marcações aleatoriamente. Pare e mostre o resultado ao professor antes de continuar.
