01 / COMPREENDER

O que permanece. O que muda.

Não vamos reaprender programação do zero. O raciocínio usado em Vue continua útil em React.

VOCÊ JÁ VIU EM VUE

Estado reativo

const titulo = ref('')

<input v-model="titulo" />

O valor do campo acompanha o estado do componente.

⇄
VOCÊ VAI USAR EM REACT

Estado com hook

const [titulo, setTitulo] = useState('')

<TextInput value={titulo}
  onChangeText={setTitulo} />

A ideia é a mesma: entrada → estado → interface.
