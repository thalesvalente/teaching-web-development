AULA 03 · DETALHE IMPORTANTE
IFMA

Por que .value no JavaScript, mas não no template?

No <script setup>

JavaScriptCOM .value
1const interessado = ref(false)
2interessado.value = true

interessado guarda a referência.

Para ler ou mudar o valor dentro dela, usamos .value.

const impede trocar a referência; não impede mudar o valor dentro do ref.

No <template>

Template VueSEM .value
1<span v-if="interessado">
2 Interesse registrado
3</span>

Neste caso, o Vue acessa o valor do ref automaticamente.

Por isso escrevemos apenas interessado.

Regra para os refs de nível superior usados nesta aula, não para toda estrutura aninhada.

Como usar a aula

← → avançam e voltam. Home vai à capa; End vai ao último slide. I abre o índice; F alterna tela cheia.

R reinicia as demos do slide. H abre esta ajuda. Esc fecha um painel. Clique nos botões das telas para experimentar.

As demos usam Vue real: runtime 3.5.13 incluído neste HTML. Não é preciso instalar nada nem ter internet. Isso não muda a versão 3.5.41 definida para o Projeto 2.

O motor usa componentes com setup() equivalentes aos SFCs exibidos. As declarações defineProps/defineEmits são representadas pelas opções de componente; as funções e os templates correspondentes são executados pelo Vue. O HTML não compila arquivos .vue nem substitui o build do projeto.

As telas do navegador são recortes ampliados para projeção. Inspetores e botões Reiniciar pertencem à apresentação, não ao software dos alunos. Trechos incompletos estão identificados; o botão Código reúne os dois arquivos completos.
