Como usar
Setas navegam. I abre o índice; R reinicia somente a demonstração do slide; N abre as notas; F alterna tela cheia. Ao digitar em um campo, os atalhos ficam suspensos.
Demonstrações com Vue 3.5.13 incluído neste arquivo. Elas usam setup/props/emits equivalentes aos SFCs; as funções exibidas são executadas pelo Vue. O HTML não compila arquivos .vue nem altera a versão do projeto da turma.
O exemplo da biblioteca tem limites 4–40 e 10–200. A atividade individual usa título 5–60 e descrição 15–300. Nenhum formulário daqui envia dados ao professor.
O resumo das prévias abrevia visualmente textos longos; os valores completos continuam no estado. Código completo: botão na barra inferior. Para imprimir uma cópia estática, use Ctrl+P. As respostas são incluídas.
